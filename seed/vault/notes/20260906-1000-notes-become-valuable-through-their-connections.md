A single note is just a thought. Its value grows with every link, because each link is a path by which the idea can resurface in a new context.

This is why linking should be effortless and constant, not an afterthought: see [[202609071030|Linking forces you to think about relationships]].

Contrast with folders, where a note can only live in one place: [[202609101000]].
